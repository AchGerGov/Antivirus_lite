# Antivirus_lite

**Antivirus_lite** — учебный антивирусный сканер с графическим интерфейсом на Python.  
Программа демонстрирует базовые методы обнаружения вредоносного ПО: сигнатурный анализ, анализ PE-файлов, эвристику, машинное обучение и мониторинг активности.

>  **Примечание:** Это учебный проект. Он не является полноценной заменой профессиональным антивирусам и не гарантирует защиту от реальных угроз. Используйте как учебную программу.

## Возможности

- **Сканирование файлов и папок** — проверка по хеш-суммам, анализ PE-структуры, вычисление энтропии.
- **Быстрое и полное сканирование** — проверка системных папок или всех дисков.
- **Карантин** — перемещение обнаруженных угроз в изолированную папку.
- **Мониторинг в реальном времени** — отслеживание изменений в ключевых директориях (`System32`, домашняя папка).
- **Сетевой мониторинг** — обнаружение подключений к подозрительным портам.
- **ML-анализ** — использование Isolation Forest для выявления аномалий среди PE-файлов.
- **Ведение логов** — запись событий в файл `guardianshield.log` и отображение в интерфейсе.
- **Обновление сигнатур** — загрузка базы с удалённого сервера (в демо-версии используется заглушка).
- **Статистика** — отображение количества проверок, угроз и файлов в карантине.
